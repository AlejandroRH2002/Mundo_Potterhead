# Fuentes autoalojadas

- Cinzel 400, subconjunto latin: `@fontsource/cinzel@5.2.8`.
- DM Sans 400, subconjunto latin: `@fontsource/dm-sans@5.2.8`.
- Distribución de los WOFF2: https://www.jsdelivr.com/package/npm/@fontsource/cinzel y https://www.jsdelivr.com/package/npm/@fontsource/dm-sans.
- Licencias SIL OFL 1.1 completas: `Cinzel-OFL.txt` y `DM-Sans-OFL.txt`, conservadas junto a las fuentes.

El navegador carga únicamente archivos locales. Solo Cinzel se precarga; ambas familias usan `font-display: swap` y fallbacks del sistema.
